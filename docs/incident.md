# Учебный разбор обращения

Сообщение: «Большой файл попал в очередь, хотя лимит 4096 KB».

Уточнения: версия/режим стенда; время запроса; имя и заявленный размер; HTTP-статус; тело ответа; наличие ключа API; повторяется ли с 4096 и 4097. Не запрашивать содержимое реального файла, если метаданных достаточно.

Локализация: воспроизвести запрос с 4097; проверить контрольный запрос с 4096; сопоставить с контрактом. При 201 для обоих проверить режим demoBug. При 422 для 4097 исходное сообщение не воспроизведено: запросить точный запрос/ответ с удалённым ключом.

Передача разработчику: приложить требования, минимальное тело запроса, ожидаемый/фактический код и идентификатор сценария TC-03. Не заменять результаты фразой «API сломан».

Критерий закрытия: 4096 принимается, 4097 отклоняется; обычный набор тестов проходит. В реальной поддержке дополнительно требуется подтверждение версии исправления и проверка в согласованной среде; в этом кейсе используется только локальный стенд.
